# Data availability

This package contains the assessment and evaluation code, operational criterion
catalog, and aggregated criterion-level results for the manuscript. The same
snapshot is prepared as Supplementary Material S1, `JBVD_Research_Materials.zip`.
An independent archive URL/DOI must be added after deposit; none is claimed here.

The 244 business plans are not publicly available because they contain
confidential commercial information and personal data. Venture-linked expert
ratings, model predictions, retrieved evidence, and run logs are also excluded
from this public snapshot. The authors do not promise access on request.

The included aggregate CSVs can be checked and used to recreate the manuscript's
tables and numerical figures without private data or model API calls. They do
not contain the observations needed to recalculate correlations, errors,
confidence intervals, or expert-disagreement measures from individual records.
That analysis requires the restricted inputs. Synthetic examples and unit tests
illustrate execution and verify calculations; they do not reproduce the study's
empirical results.
